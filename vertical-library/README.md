# Vertical Library — Index

Compounding knowledge base for Avenfield list-building. One file per broad service-category vertical. This library informs the iteration loop; it does not replace it.

---

## Operating Rules

- **Mode C hybrid writes.** Agent auto-logs raw observations (facts); proposes rule / construction-note changes for Momin's approval (interpretations); 3-campaign threshold before a pattern becomes a proposed rule. Full contract: `~/.claude/projects/-Users-mominsharif-avenfield/memory/project_vertical_library_contract.md`
- **Broad vertical definitions.** Service category is the unit. No sub-archetypes. If a firm provides the service, it qualifies — regardless of size, sector, or sub-model. Rule: `feedback_broad_verticals_no_subdivision.md`
- **Filters are outputs, never paste-ready inputs.** Each file stores Filter Construction Notes; the seed → observe → derive → test loop runs fresh every campaign. Rule: `feedback_filters_are_outputs_not_inputs.md`
- **Agents propose, Momin approves.** Agents research seeds, draft proposals with confidence tiers, present for 60-second spot-check. Never ask Momin to produce raw material the agent could research itself. Rule: `feedback_agents_propose_momin_approves.md`

## Schema (per-vertical file structure)

1. Header (status, TAM, campaigns run, last updated, cross-refs)
2. Definition (what counts, broad inclusion rule, sniff test, span)
3. Seed Companies — CONFIRMED truth set + FLAGGED calibration anchors + AMBIGUOUS grey-zone anchor
4. Filter Construction Notes (prose, NOT paste-ready)
5. Scorer Rules (CONFIRMED / FLAGGED / AMBIGUOUS)
6. Contamination Patterns (proven, 3+ campaigns)
7. Trending Observations (2x seen, not yet rules)
8. Campaign Log (last ~5 runs)
9. Raw Observations Dump (auto-append FLAGGED list)
